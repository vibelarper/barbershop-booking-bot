# 💈 Telegram Booking Bot (Запись клиентов + Excel)

Telegram-бот на **Python (aiogram 3)** для автоматизации записи клиентов в сферу услуг (барбершоп, салон красоты, автосервис) с сохранением заявок в Excel-таблицу.

👉 **Демо-версия в Telegram:** [@ваш_второй_бот](https://t.me)

---

## ✨ Основной функционал
* **Интерактивное меню:** быстрый доступ к прайс-листу, адресу и графику работы.
* **Пошаговая запись (FSM):** сбор имени клиента, выбранной услуги, желаемого времени и номера телефона.
* **Мгновенные уведомления:** отправка оформленной заявки администратору в Telegram сразу после заполнения анкеты.
* **Экспорт в Excel (`openpyxl`):** автоматическая запись всех клиентов в файл `appointments.xlsx` и выгрузка актуальной таблицы по команде `/excel`.

## 🛠 Стек технологий
* **Python 3.11+**
* **Aiogram 3.x** (машина состояний FSM)
* **OpenPyXL** (генерация и обновление `.xlsx` отчётов)

## 🚀 Как запустить

1. **Скачайте проект и установите библиотеки:**
   ```bash
   git clone https://github.com
   cd barbershop-booking-bot
   pip install -r requirements.txt
   ```

2. **Укажите переменные окружения (в `.env` или на сервере Railway):**
   ```env
   BOT_TOKEN=ваш_токен_от_BotFather
   ADMIN_ID=ваш_цифровой_telegram_id
   ```

3. **Запустите скрипт:**
   ```bash
   python bot.py
   ```
